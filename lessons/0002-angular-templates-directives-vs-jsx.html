Lesson 0002: Angular Templates & Directives vs. JSX

Translating *ngIf, *ngFor, [ngClass], [ngStyle], and pipes to standard JavaScript expressions, .map(), and modern utilities

1. Template Directives vs. JavaScript Expressions

Angular uses a domain-specific template language processed by the Angular compiler (Ivy), providing built-in structural directives (*ngIf, *ngFor, *ngSwitch) or modern control flow blocks (@if, @for, @switch). In React, there is no template micro-syntax: JSX is simply JavaScript expressions that evaluate to React elements.

Concept Angular (Web) React (Web)
Conditional Rendering *ngIf="isOpen" or @if (isOpen) {isOpen && <Modal />}
If / Else Branching *ngIf="auth; else guest" {auth ? <Dashboard /> : <Guest />}
List Iteration & Keys *ngFor="let item of list; trackBy: id" or @for (item of list; track item.id) {list.map(item => <Row key={item.id} item={item} />)}
Conditional Classes [ngClass]="{ active: isActive, error: isError }" className={clsx({ active: isActive, error: isError })}
Dynamic Inline Styles [ngStyle]="{ color: active ? 'blue' : 'gray' }" style={{ color: active ? 'blue' : 'gray' }}
Data Formatting (Pipes) {{ date | date:'short' }} {formatDate(date)} or Intl.DateTimeFormat
Wrapper / Fragments <ng-container>...</ng-container> <>...</> (<React.Fragment>)
📦 NPM Library Spotlight: clsx

In Angular, [ngClass] allows passing an object where keys are class names and values are booleans (e.g. [ngClass]="{ 'active': isActive }"). React's standard className prop only accepts plain strings. The industry-standard npm library to get the exact same object syntax is clsx (a tiny ~230B utility):

# Install clsx
npm install clsx

# Usage in React:
import clsx from 'clsx';

// Combines static & conditional classes seamlessly:
<button className={clsx('btn', 'btn-primary', { 'is-loading': loading, 'is-disabled': disabled })} />

2. Deep Dive: List Reconciliation (`trackBy` vs. `key`)

In Angular, trackBy (or `@for (...; track id)`) tells the change detector how to identify which DOM nodes moved, changed, or were removed. In React, the key prop serves the identical purpose during Virtual DOM reconciliation:

The Rule of Keys:
  • Unique & Stable: Always use unique IDs from your data model (e.g. item.id).
  • Never use array index if the list mutates: Using key={index} breaks component state, animations, and input focus when items are inserted, removed, or sorted.
  • Top-Level Placement: The key prop must always be placed on the outermost JSX element returned inside the .map() callback.

3. Side-by-Side Code Comparison: User Directory with Filtering & Formatting

Compare how an interactive user list with conditional badges, dynamic status classes, and date formatting is implemented in Angular vs React:

Angular Component (HTML Template)

<!-- user-list.component.html -->
<div class="directory">
  <h2>Team Directory ({{ users.length }})</h2>

  <!-- Conditional rendering -->
  <div *ngIf="isLoading; else listContent" class="loader">
    Loading team members...
  </div>

  <ng-template #listContent>
    <p *ngIf="users.length === 0" class="empty">
      No team members found.
    </p>

    <ul class="user-list">
      <!-- List iteration with trackBy -->
      <li
        *ngFor="let user of users; trackBy: trackByUserId"
        class="user-row"
        [ngClass]="{ 'is-admin': user.role === 'admin', 'is-offline': !user.isOnline }"
        [ngStyle]="{ borderLeftColor: user.themeColor }"
      >
        <span class="user-name">{{ user.name }}</span>
        <span *ngIf="user.role === 'admin'" class="badge">Admin</span>
        
        <!-- Pipe formatting -->
        <time>Joined: {{ user.joinedAt | date:'mediumDate' }}</time>
      </li>
    </ul>
  </ng-template>
</div>

React Component (TSX + Plain JS)

// UserList.tsx
import React from 'react';
import clsx from 'clsx'; // npm install clsx

interface User {
  id: string;
  name: string;
  role: 'admin' | 'member';
  isOnline: boolean;
  themeColor: string;
  joinedAt: string;
}

interface UserListProps {
  users: User[];
  isLoading: boolean;
}

// Pure JS formatter (replaces Angular DatePipe)
function formatDate(isoString: string): string {
  return new Intl.DateTimeFormat('en-US', { dateStyle: 'medium' }).format(new Date(isoString));
}

export function UserList({ users, isLoading }: UserListProps) {
  if (isLoading) {
    return <div className="loader">Loading team members...</div>;
  }

  return (
    <div className="directory">
      <h2>Team Directory ({users.length})</h2>

      {users.length === 0 ? (
        <p className="empty">No team members found.</p>
      ) : (
        <ul className="user-list">
          {users.map((user) => (
            <li
              key={user.id}
              className={clsx('user-row', {
                'is-admin': user.role === 'admin',
                'is-offline': !user.isOnline,
              })}
              style={{ borderLeftColor: user.themeColor }}
            >
              <span className="user-name">{user.name}</span>
              {user.role === 'admin' && <span className="badge">Admin</span>}
              <time>Joined: {formatDate(user.joinedAt)}</time>
            </li>
          ))}
        </ul>
      )}
    </div>
  );
}

4. Critical JSX Gotchas for Angular Leads

  1. The 0 && <Component /> Trap:
    In JavaScript, 0 && "anything" evaluates to 0 (not false). If unreadCount = 0, writing {unreadCount && <Badge />} will render a literal 0 onto your screen!
    Fix: Explicitly cast to boolean: {unreadCount > 0 && <Badge />} or {Boolean(unreadCount) && <Badge />}.
  2. HTML Attributes are CamelCase in React:
    Use className (not class), htmlFor (not for), tabIndex (not tabindex), and onClick (not (click) or onclick).
  3. Inline Styles are Objects, Not Strings:
    In Angular you might write style="background-color: red;" or [style.background-color]="color". In React, pass a JavaScript object: style={{ backgroundColor: color }}.
  4. Returning Sibling Elements:
    JSX components must return a single root element. If you don't want a wrapper <div> in the DOM, use React Fragments: <><Header /><Main /></> (equivalent to <ng-container>).
