Lesson 0012: Real-Time Data Pipelines & WebSockets

Translating Angular RxJS WebSocketSubject & SSE streams to React custom streaming hooks and resilient real-time state

1. Real-Time Streaming Translation Matrix

In Angular, real-time architectures utilize RxJS's webSocket() (WebSocketSubject) piped into Angular templates via the | async pipe. In React, real-time streaming is built using composable custom hooks (such as react-use-websocket or custom useWebSocket / useEventSource hooks) with explicit connection lifecycles, exponential backoff reconnects, and integration with TanStack Query or local state.

Concept Angular (Web) React (Web)
WebSocket Primitive webSocket<T>('wss://...') (WebSocketSubject) Native WebSocket inside useEffect / react-use-websocket hook
Server-Sent Events (SSE) Wrapping EventSource in an RxJS Observable.create() Custom useEventSource(url) hook or Fetch Streaming with ReadableStreamDefaultReader
Automatic Reconnection pipe(retry({ delay: ... })) RxJS operator Exponential backoff timeout inside hook cleanup/reconnect loops or built into react-use-websocket
Piping Stream into UI messages$ | async in Angular template const { lastJsonMessage, sendJsonMessage } = useWebSocket(url);
Cache Invalidation on Event RxJS Subject triggers service reload WebSocket event invokes queryClient.setQueryData() or queryClient.invalidateQueries() in TanStack Query

2. Architecture: Feeding Real-Time Streams into TanStack Query Cache

A premier architectural pattern in modern React apps is using WebSockets not as the primary data fetcher, but as a live invalidation and delta stream that updates the TanStack Query cache in place:

Live Cache Patching Pattern: 
import { useQueryClient } from '@tanstack/react-query';
import useWebSocket from 'react-use-websocket';

export function useLiveOrderUpdates() {
  const queryClient = useQueryClient();

  useWebSocket('wss://api.domain.com/orders/feed', {
    onMessage: (event) => {
      const updatedOrder = JSON.parse(event.data);
      // Immediately patch the TanStack query cache without refetching from HTTP!
      queryClient.setQueryData(['orders'], (oldOrders: any[] = []) =>
        oldOrders.map(o => o.id === updatedOrder.id ? updatedOrder : o)
      );
    }
  });
}

3. Side-by-Side Code Comparison: Real-Time Crypto Price Ticker

Angular RxJS WebSocketSubject

// price-ticker.component.ts
import { Component, OnInit, OnDestroy } from '@angular/core';
import { webSocket, WebSocketSubject } from 'rxjs/webSocket';
import { Observable, retry } from 'rxjs';

interface PriceUpdate {
  symbol: string;
  price: number;
}

@Component({
  selector: 'app-price-ticker',
  template: `
    <div class="ticker">
      @if (price$ | async; as price) {
        <span>{{ price.symbol }}: ${{ price.price.toFixed(2) }}</span>
      } @else {
        <span>Connecting to live stream...</span>
      }
    </div>
  `
})
export class PriceTickerComponent implements OnInit, OnDestroy {
  private socket$!: WebSocketSubject<PriceUpdate>;
  price$!: Observable<PriceUpdate>;

  ngOnInit() {
    this.socket$ = webSocket('wss://stream.crypto.com/live');
    this.price$ = this.socket$.pipe(
      retry({ delay: 3000 })
    );
  }

  ngOnDestroy() {
    this.socket$.complete();
  }
}

React useWebSocket Hook

// PriceTicker.tsx
import React from 'react';
import useWebSocket, { ReadyState } from 'react-use-websocket';

interface PriceUpdate {
  symbol: string;
  price: number;
}

export function PriceTicker() {
  const { lastJsonMessage, readyState } = useWebSocket<PriceUpdate>(
    'wss://stream.crypto.com/live',
    {
      shouldReconnect: () => true,
      reconnectInterval: 3000,
    }
  );

  const connectionStatus = {
    [ReadyState.CONNECTING]: 'Connecting...',
    [ReadyState.OPEN]: 'Live',
    [ReadyState.CLOSING]: 'Closing...',
    [ReadyState.CLOSED]: 'Disconnected',
    [ReadyState.UNINSTANTIATED]: 'Uninstantiated',
  }[readyState];

  return (
    <div className="ticker">
      <span className="status-badge">{connectionStatus}</span>
      {lastJsonMessage ? (
        <span>
          {lastJsonMessage.symbol}: ${lastJsonMessage.price.toFixed(2)}
        </span>
      ) : (
        <span>Awaiting incoming stream data...</span>
      )}
    </div>
  );
}

4. Key Architectural Takeaways for Angular Leads

  • Automatic Connection Cleanup: React hooks automatically handle WebSocket disconnects and unsubscribe events when components unmount, mirroring ngOnDestroy without boilerplate teardown code.
  • Bidirectional Messaging without Boilerplate: Functions like sendJsonMessage({ type: 'SUBSCRIBE' }) allow child components to trigger websocket transmissions directly via callbacks.
