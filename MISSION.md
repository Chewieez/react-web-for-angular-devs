# Mission: Modern React Web Mastery for Angular Leads & Engineers

## Why
Transition deep enterprise Angular expertise (Services, Dependency Injection, Signals, RxJS, Routing, Reactive Forms, NgRx) into production-grade, modern React Web development (Next.js, React 19, TypeScript, React Hook Form, TanStack Query, Zustand, React Server Components).

## Success looks like
- Confidently architecting high-scale React web applications using modern paradigms (Functional Components, Custom Hooks, Server Components, Route Handlers).
- Seamlessly translating Angular concepts to React patterns without falling into anti-patterns (e.g. over-using `useEffect`, prop drilling vs context/Zustand, reference inequality bugs).
- Building high-performance, accessible web applications with modern state management (Signals <-> `useState`/Zustand, RxJS <-> TanStack Query).
- Understanding React Server Components (RSC), SSR hydration mechanics, and Next.js / React Router v7 architecture.

## Constraints
- Tailored specifically for engineers with strong Angular / TypeScript backgrounds.
- High density, minimal fluff, structured around direct concept translation matrices.
